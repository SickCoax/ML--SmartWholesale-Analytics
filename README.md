# Wholesale Customer Segmentation

Customer segmentation project using **K-Means Clustering** on the Wholesale Customers dataset to identify groups of customers based on their purchasing behavior.

## 📌 Features Used
- Fresh
- Milk
- Grocery
- Frozen
- Detergents_Paper
- Delicassen

## 🔧 Workflow
- Data Cleaning
- Feature Scaling
- Elbow Method
- Silhouette Score Analysis
- K-Means Clustering
- PCA Visualization

## 📊 Results
The model segmented customers into **6 clusters**, representing different purchasing patterns such as:
- Retail Stores
- Fresh Food Buyers
- Small Customers
- General Wholesale Customers
- Specialty Food Customers
- Bulk Buyers

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## 🚀 Goal
Help businesses understand customer purchasing patterns for better targeting and decision-making.
